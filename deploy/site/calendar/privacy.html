Privacy Policy

Last updated: September 17, 2026

Even G2 Calendar Assistant is a personal, single-operator application. It is not a shared multi-user calendar service.

Data used

The application processes voice transcripts, conversation context, calendar event details, and the operator's fixed invitation recipient when needed to perform an explicitly requested task.

Google Calendar access

Google Calendar access is limited to the dedicated assistant calendar and owned events. Calendar changes require an in-session preview and confirmation. The application does not claim access to every calendar in the operator's account.

Storage and sharing

Runtime credentials, conversation records, task state, and generated documents are stored on the operator-controlled server. Data is sent only to service providers required for requested functionality, such as Google Calendar, email delivery, and the configured AI provider. Data is not sold.

Security and retention

Credentials are kept outside the public source repository. Network access uses HTTPS, and the backend service is not directly exposed to the internet. The operator controls retention and deletion of server data and calendar events.

Contact

Security issues can be reported privately through the project's GitHub security advisory page.
