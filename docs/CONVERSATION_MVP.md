# Conversation MVP — 已确认的近期范围

状态：需求已确认，本地实验版已实现部分能力，见 [Conversation Lab](./CONVERSATION_LAB.md)。G2/R1 及完整体验尚未验收。本文优先于旧 Development Plan 中冲突的近期交互安排；不改变长期路线。

## 用户体验

- 用户从 Even 手机 App 或眼镜菜单打开应用，可用 R1 操作菜单。不依赖原生 Hey Even 启动第三方插件、全局自定义手势或定时唤起。
- 打开后显示明确的收音状态，正常说话、阅读文字回答、继续追问；不要求每一轮按发送键。
- 保留 OpenAI 为默认 STT 方案，不恢复 Soniox 对照实验。语音转写与对话推理是分开的职责。
- 自动判断轮次结束，需要结合语音活动、停顿和语义完整性；具体实现与参数经接口核验和中英混说测试确定。不能承诺完全不抢话或零等待。
- R1 是补充控制：听取时手动提交；生成回答时取消旧回答并进入听取状态。暂停/恢复有明确入口和 HUD 状态，具体手势在真机上验证，不覆盖系统保留手势。
- 回答以文字呈现；生成回答时允许用户开口插话。检测到疑似插话先暂停旧输出，确认新输入后取消旧回答并处理新一轮；为误触发提供恢复路径。
- 长对话保留上下文，并为连接重建和长历史摘要预留实现；逻辑会话不等于一条永不掉线的连接。

## 结束会话与退出

- 支持“再见”“退下吧”等表达，但它们只是意图判断的例子，不是命中即退出的字符串规则。
- 对话推理区分直接结束指令、引用、否定、改写文本及普通讨论；依据稳定的完整输入和上下文判断，不根据转写 delta 执行退出。
- 意图不清楚时澄清，不擅自退出。输入转录不代表授权执行任意动作。
- 确认结束意图后停止麦克风采集和音频上送、取消尚未完成的回答，保存本次会话上下文，并请求官方系统退出确认框。
- 用户接受用 R1 确认退出。确认前显示“已停止收音，等待退出确认”；取消退出则保留暂停状态并明确显示“退出已取消，麦克风仍暂停；点击一次继续”，显式单击后才重新收音。
- 保存失败不能阻止停止收音；应明确提示未保存状态。插话/取消回答不等于撤销未来已执行的工具动作。
- 区分“这一轮说完”“暂停对话”“退出应用”。阅读时的安静不能直接视为退出意图；空闲暂停策略需可见且经过调试。

## 实施顺序

1. 在已有单轮转录 POC 上定义多轮会话状态、稳定输入提交和自动轮次判断，先用软件测试验证。
2. 接入文本对话推理与上下文，加入插话取消、旧输出隔离和结束意图判断。
3. 接入 Even Hub HUD、麦克风与 R1，验证开始/暂停/提交/退出完整链路。
4. 使用 G2 + iPhone + R1 验证中英文混说、阅读停顿、环境噪声、插话、系统确认及退出后原生功能恢复。

原始 POC 仍是单连接、单次手动提交的实时转录。新增本地 Conversation Lab 提供自动音频分段、语义完整性与退出意图判断、多轮文字对话、生成取消和浏览器测试页；限制与验收记录见其文档。完整 G2 体验尚未完成。

## 验收用例

- 一次启动完成至少 10 轮中英混合追问，不依赖每轮手动提交，上下文保持一致。
- “把 deployment date 改到……next Friday，不要删除原来的备注”：覆盖思考停顿及语言切换，不提前执行残缺指令。
- 文字回答生成中说“等一下，只看下午的”：旧回答停止，新回答使用更正后的要求，迟到的旧输出不覆盖新回答。
- 直接说“退下吧”触发停止收音和退出确认；“不要退出”“把备注改成再见”“他说了再见”均不退出。
- 系统确认框出现期间不再采集/发送音频；确认后退出；取消后保持暂停而非悄悄恢复，并提示一次点击即可继续。
- 断线、保存失败、误判插话、环境噪声均有可见状态和安全恢复路径。

## 后续工具阶段（不在本版实现）

最新范围调整：用户已确认先加入 OpenAI 内置只读联网搜索，已接入本地实验版；以下文件生成/发送等写操作仍延后。详见 [Conversation Lab](./CONVERSATION_LAB.md)。

- 根据对话生成 Markdown 文件，并发送给用户。
- 其他工具逐项加入；文件发送渠道、目标账号、隐私和确认规则届时单独确定，不预设邮件或第三方平台。
- 本版可定义后续工具接口边界，但不提前实现文件发送、日历写入、多模型路由或任意外部执行。
- 不承诺与原生语音应用同时占用麦克风、永久后台常驻或无限时长在线。
