## 实现范围

- nearby 结构化字段采用逐字段 keep/set/clear，明确区分省略与清除；有限类型白名单不解析用户关键词。
- 当前任务内保存条件，模型选择 continue/replace；代码生成任务 ID，过期／取消／session reset 清理。未来出行不使用 openNow 排除临时关门店。
- 最多十候选先筛选，再最多五个进入矩阵；price/status 映射、未知保留、重复 ID 去重、坐标粗排、食物／类型弱先验。
- 用户看到真实 Routes 时长、原始 Google 评分、营业／价格不确定性，不看到直线距离冒充 ETA。
- 澄清回答选原候选，不再拼搜索词；recommend 一次、specific 两次、delegated 零次。达到上限提供可纠正假设；非法索引不能引入新地点。
- 原有简洁的代码推荐文案继续承担数值和排序解释；模型承担意图和候选语义选择。此轮未额外增加自由生成整段推荐文案的模型调用，避免新的事实幻觉和延迟。若本地体验不足，再评估受事实约束的短理由生成。
- metadata-only nearby 计数：prefiltered 为过滤数量，routed 为尝试进入矩阵的候选数量；assumed/clarified 为对话次数。这些不是计费真值，计费仍由 provider ledger 记录。

## 官方接口核验

- [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)：所有对象字段 required、additionalProperties=false；以操作字段区分 keep／clear，不把 nullable 当成两种语义。
- [Google Places 字段档位](https://developers.google.com/maps/documentation/places/web-service/data-fields)：currentOpeningHours 与 priceLevel 不高于已使用的 Text Search Enterprise；businessStatus/location 为更低档。未请求评论或 Atmosphere 字段。
- [Places 类型](https://developers.google.com/maps/documentation/places/web-service/place-types)：有限排除词表来源；未宣称覆盖所有官方类型。

边界：这是单次样本、真实分类和 Places/Routes 的有界集成验证，不是 soak、语音准确率证明或完整真机验收。澄清次数和非法模型输出由离线故障注入覆盖；现场推荐质量仍需用户验收。真实店铺营业状态随时间变化；若全被过滤，脚本会失败并要求核对，不能换假数据冒充通过。
